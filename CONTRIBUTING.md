# Contributing to nexat-trace

We welcome contributions of all kinds, including bug reports, feature requests, code, and documentation improvements.

All contributions are subject to the Code of Conduct.


## Reporting Issues

Please use one of the templates if it fits your issue.


## Submitting Pull Requests 

- Fork the repository and create a branch with your changes.
- Update documentation as needed.
- Submit a pull request to the ```dev``` branch with a clear description of your changes.


## Coding guidelines

- Use snake_case
- Follow the ```ruff``` linter setup defined in ```pyproject.toml```
- Run ```ruff``` linter before submitting.
